Extended the AFTAB RISC-V processor at CINI Laboratory, focusing on instruction-set customization for machine-learning workloads and platform-level interrupt handling.

## Custom Instructions for Machine Learning

Extended the RISC-V instruction set with specialized instructions for vector operations and optimized pipeline efficiency to reduce latency in machine-learning workloads. This work connected application-level computational requirements with instruction-set and microarchitectural design.

## Platform-Level Interrupt Controller

Developed a platform-level interrupt controller (PLIC) for AFTAB, supporting interrupt prioritization and routing. Multiple priority levels enabled finer control over interrupt handling, extending the processor’s ability to interact with system peripherals.

## FPGA Implementation

My related FPGA work included implementing the AFTAB processor on the PYNQ-Z2 platform, complementing the processor-design work with practical hardware prototyping.
